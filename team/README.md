# Team

| File | Content |
|---|---|
| `team.json` | **Names, course, university, date**: the single source used by every deliverable |
| `WORK_DIVISION.md` | Timing, slide ranges, report ownership, demo mapping |
| `Member_1_Guide.pdf` … `Member_4_Guide.pdf` | Per-presenter guide: script, report sections, demo role, Q&A, common core |
| `src/` | Guide content (`guides_content.js`) and builder (`build_guides.js`) |

Rebuild the guides after editing names or content: `npm run build:guides` (from the repository root; needs LibreOffice for the PDFs).
